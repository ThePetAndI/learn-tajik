# Формат данных курса

Сейчас в курсе: **20 разделов, 103 уровня, 402 слова, 150 фраз, 35 букв,
26 диалогов, 22 изафетные пары, 14 правил**.

Весь учебный материал лежит здесь в JSON и не зависит от кода. Можно править руками:
после `npm run build` (или перезагрузки дев-сервера) изменения подхватятся.

Проверить файлы перед сборкой:

```bash
npm run validate:content
```

Скрипт ругается на дубликаты id, битые ссылки, пустые поля и на буквы, которых нет в
таджикском алфавите (частая опечатка — русские **ц щ ы ь**, их в таджикском нет).

## Файлы

```
content/
  alphabet.json        35 букв: звучание, отличия от русского, слова-примеры
  course.json          разделы и уровни — из чего собирается карта
  words/*.json         слова, разбитые по темам (имя файла роли не играет)
  phrases/*.json       фразы и предложения
  dialogues.json       мини-диалоги: реплика и ответ на неё
  izafet.json          изафетные пары: падар + и + ман
  rules.json           правила грамматики — карточки в начале раздела или урока
  REVIEW.md            всё, что помечено "verified": false — на проверку носителем
```

Файлы в `words/` и `phrases/` читаются все подряд, так что можно добавить свой
`words/99-moi-slova.json` — он попадёт в игру, если на слова сошлётся какой-нибудь уровень.

## Слово

`words/04-family.json`:

```json
{
  "theme": "family",
  "words": [
    {
      "id": "w_padar",
      "tg": "падар",
      "ru": "отец",
      "pos": "noun",
      "theme": "family",
      "example": { "tg": "Падари ман муаллим аст.", "ru": "Мой отец — учитель." },
      "audio": null,
      "verified": true,
      "note": ""
    }
  ]
}
```

| Поле | Обязательное | Что значит |
|---|---|---|
| `id` | да | Вид `w_slug`: латиница, нижний регистр, цифры и `_`. Уникален на весь курс |
| `tg` | да | Слово по-таджикски, кириллицей, в нормальной форме |
| `ru` | да | Перевод. Несколько значений — через запятую |
| `pos` | да | Часть речи: `noun` `verb` `adj` `adv` `pron` `num` `prep` `conj` `part` `interj` `phrase` |
| `theme` | да | Тема — по ней подбираются правдоподобные неверные варианты в квизе |
| `num` | нет | Число, которое обозначает слово. Только у числительных — по нему работает мини-игра «Какое это число?» |
| `example` | нет | Пример употребления: `{ "tg": "...", "ru": "..." }` |
| `audio` | нет | Задел на будущее. Сейчас всегда `null`, озвучки в игре нет |
| `verified` | да | `false` — если в слове или форме нет уверенности |
| `note` | нет | Заметка: вариант, нюанс употребления, вопрос к проверке |

`id` менять нельзя после того, как вы поиграли: к нему привязана статистика повторения.
Если слово удалить, его статистика просто перестанет учитываться.

## Фраза

`phrases/01-greetings.json`:

```json
{
  "theme": "greetings",
  "phrases": [
    {
      "id": "p_hello_how_are_you",
      "tg": "Салом, шумо чӣ хел?",
      "ru": "Здравствуйте, как вы?",
      "theme": "greetings",
      "words": ["w_salom"],
      "alt": [],
      "audio": null,
      "verified": true,
      "note": "вежливая форма на «вы»"
    }
  ]
}
```

`words` — необязательный список слов, которые встречаются во фразе; используется
мини-игрой «Собери фразу» и для учёта повторения. Все id должны существовать.

`alt` — необязательный список других верных переводов той же русской фразы. Нужен
мини-игре «Напиши фразу», где ответ набирают руками: по-таджикски подлежащее-местоимение
часто опускают («Ба хона меравам» вместо «Ман ба хона меравам»), и таких мест в языке
много. Всё, что стоит в `alt`, засчитывается наравне с `tg`. Пока список пуст везде:
заполнять его есть смысл только с носителем — иначе мы засчитываем то, в чём сами
не уверены.

Писать просят только фразы с `verified: true`: узнать форму, в которой мы не уверены, —
полбеды, а вот заставить её написать и снять жизнь за отклонение — уже вред.

`gloss` — необязательный список `{ "tg", "ru" }`: значение слова именно в этой фразе,
если оно не то, что в словаре. Перед первым заданием на фразу игрок видит её карточку:
перевод целиком и каждое слово по отдельности, со значением из словаря. Иногда словарное
значение сбивает — «хайр» в словаре «пока», а в «Шаб ба хайр» это «добро». Тогда
достаточно указать только это слово:

```json
"gloss": [{ "tg": "хайр", "ru": "добро, благо — в пожеланиях «... ба хайр»" }]
```

Остальные слова по-прежнему берутся из словаря. То же поле есть у разговоров
в `dialogues.json`. Проверка ругается, если слово из `gloss` не входит в `words` записи:
переопределять значение слова, которого во фразе нет, — это опечатка.

## Диалог

`dialogues.json` — материал для мини-игры «Что ответишь?».

```json
{
  "dialogues": [
    {
      "id": "d_ahvol",
      "theme": "greetings",
      "ask": { "tg": "Аҳволат чӣ хел?", "ru": "Как твои дела?" },
      "reply": { "tg": "Раҳмат, нағз.", "ru": "Спасибо, хорошо." },
      "words": ["w_rahmat"],
      "audio": null,
      "verified": false,
      "note": "проверить «аҳволат чӣ хел» против «корҳоят чӣ хел»"
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `id` | Вид `d_slug` |
| `theme` | Тема — по ней диалог сам попадает на уровни с такими словами |
| `ask` | Реплика собеседника. Её перевод игрок видит сразу |
| `reply` | Верный ответ. Его перевод откроется только после выбора |
| `wrong` | Необязательно: свои неверные варианты. Если не задать, возьмутся ответы из других диалогов — они верны сами по себе, но не к этому вопросу |

Диалоги не перечисляются в `course.json`: связь по теме. Дописали диалог с
`"theme": "family"` — он сам появится на семейных уровнях.

## Изафет

`izafet.json` — материал для мини-игры «Собери по-таджикски».

```json
{
  "izafet": [
    {
      "id": "iz_padari_man",
      "theme": "family",
      "head": "падар",
      "mod": "ман",
      "tg": "падари ман",
      "ru": "мой отец",
      "words": ["w_padar", "w_man"],
      "audio": null,
      "verified": true,
      "note": ""
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `head` | Главное слово — к нему приклеивается изафет |
| `mod` | Зависимое слово, идёт вторым |
| `tg` | Готовая форма целиком |
| `ru` | Перевод. По-русски порядок обратный — этому и учит задание |

Проверка при сборке следит, чтобы `head` + «и» + пробел + `mod` в точности давало `tg`.
Где склейка не по общему правилу (`зиндагӣ` → `зиндагии`, а не `зиндагӣи`), задание
не соберётся, и `npm run validate:content` скажет об этом ошибкой: показать игроку
неверное написание хуже, чем не показать задание.

Связь с уровнями — тоже по теме.

## Алфавит

`alphabet.json`:

```json
{
  "letters": [
    {
      "lower": "ғ",
      "upper": "Ғ",
      "name": "ғе",
      "sound": "звук между «г» и украинским «г», как французское r",
      "ru": null,
      "special": true,
      "note": "в русском алфавите такой буквы нет",
      "examples": ["w_gizo"],
      "verified": true
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `lower` / `upper` | Сама буква в двух регистрах |
| `name` | Как буква называется |
| `sound` | Описание звука по-русски |
| `ru` | Ближайшая русская буква или `null`, если соответствия нет |
| `special` | `true` для шести букв, которых нет в русском: ғ ӣ қ ӯ ҳ ҷ |
| `examples` | id слов-примеров из `words/` |

Отдельных уроков про буквы нет. Буква без русского двойника (`"ru": null` — это ғ ӣ қ ӯ ҳ ҷ
и ъ) объясняется карточкой в том уроке, где впервые встречается в словах или фразах,
прямо перед первым словом с ней. Примеры на карточке — слова этого же урока; `examples`
отсюда берутся, только если своих слов с буквой в уроке нет. Поэтому порядок, в котором
буквы знакомятся, задаёт сама карта: переставили уроки — поменялся и он.

## Курс

`course.json` описывает карту: разделы сверху вниз, внутри — уровни.

```json
{
  "sections": [
    {
      "id": "s04",
      "title": "Семья",
      "levels": [
        {
          "id": "s04_l1",
          "title": "Родители",
          "words": ["w_padar", "w_modar"],
          "phrases": ["p_my_father"],
          "exercises": "auto",
          "boss": false
        }
      ]
    }
  ]
}
```

| Поле уровня | Что значит |
|---|---|
| `id` | Уникальный, вида `s04_l1`. К нему привязан прогресс и звёзды |
| `title` | Подпись уровня |
| `words` / `phrases` | Из чего собираются задания |
| `exercises` | `"auto"` — движок сам смешает 6–10 заданий разных типов. Либо явный список, например `[{ "type": "letter_wheel" }, { "type": "quiz_tg_ru" }]` |
| `boss` | `true` — уровень-сундук, последний в разделе |

Порядок разделов и уровней в файле = порядок на карте.

Два правила подбора слов, которые проверяют тесты:

- **В одном уроке нет двух новых слов, отличающихся одной буквой**: «хуб» и «хуш», «бо»
  и «бе», «ин» и «он» разводятся по разным урокам — вместе они запоминаются как одно
  пятно. Исключения — числа и месяцы, их учат подряд («ҳафт», «ҳашт»; «июн», «июл»).
- **Разговор попадает в урок, только если все его слова — из этого урока или уже
  пройдены.** Разговоры цепляются по теме, и без этого правила первый урок получал
  бы разговор со словами из пятого.

## Правило

`rules.json` — карточки грамматики, которые встают первым экраном урока:

```json
{
  "rules": [
    {
      "id": "r_polite",
      "section": "s01",
      "level": "s01_l5",
      "title": "«Шумо» вежливее, чем «ту»",
      "body": "Как и в русском, есть «ты» и «вы»…\n\nВторой абзац.",
      "examples": [{ "tg": "Шумо чӣ хел?", "ru": "Как вы?" }],
      "verified": true,
      "note": ""
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `section` | Раздел. Без `level` правило показывается в первом уроке раздела |
| `level` | Необязательно: урок, где правило нужнее, — там, где тема впервые встречается. Урок должен быть из того же раздела |
| `body` | Текст; абзацы разделяются пустой строкой (`\n\n`) |
| `examples` | Пары «по-таджикски — по-русски» под текстом |

Правило показывается только при первом прохождении урока: повторять его при каждой
переигровке незачем.

## Озвучка

Поле `audio` есть у слов и у букв, и пока везде `null`. Приложение от этого
работает молча: кнопка «послушать» появляется только там, где запись есть.

Чтобы добавить:

1. Положите файл в `public/audio/words/` или `public/audio/letters/`.
2. Пропишите путь в JSON: `"audio": "audio/words/w_salom.mp3"` — без ведущего слэша,
   иначе сломается на GitHub Pages в подкаталоге.
3. Проверьте: `npm run audio:check` покажет покрытие и найдёт битые ссылки.

Буквы попадают в precache целиком — их мало, и нужны они с первого урока.
Слова кэшируются по мере проигрывания: четыреста файлов раздули бы установку,
а услышанное один раз дальше доступно офлайн.

Начинать стоит с 35 букв и полусотни самых частых слов — это примерно час записи.

**Синтеза речи в приложении нет и не планируется.** Русский голос прочитает
«ҳавз» как «хавз» и закрепит неверное произношение — ровно то, против чего
сделано задание «пропущенная буква». Нужен носитель.

## Про `verified`

Точность важнее объёма. Всё, в чём нет уверенности — редкое слово, разговорный оборот,
глагольная форма — помечается `"verified": false` и попадает в
[REVIEW.md](REVIEW.md) с пояснением, что именно вызывает сомнение. В игре такие слова
работают наравне с остальными; пометка нужна, чтобы их было легко найти и перепроверить.

Исправили слово — поставьте `"verified": true` и уберите строку из `REVIEW.md`.
