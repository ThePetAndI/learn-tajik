# Формат данных курса

Сейчас в курсе: **21 раздел, 105 уровней, 408 слов, 153 фразы, 35 букв,
26 диалогов, 22 изафетные пары**.

Весь учебный материал лежит здесь в JSON и не зависит от кода. Можно править руками:
после `npm run build` (или перезагрузки дев-сервера) изменения подхватятся.

Проверить файлы перед сборкой:

```bash
npm run validate:content
```

Скрипт ругается на дубликаты id, битые ссылки, пустые поля и на буквы, которых нет в
таджикском алфавите (частая опечатка — русские **ц щ ы ь**, их в таджикском нет).

## Файлы

```
content/
  alphabet.json        35 букв: звучание, отличия от русского, слова-примеры
  course.json          разделы и уровни — из чего собирается карта
  words/*.json         слова, разбитые по темам (имя файла роли не играет)
  phrases/*.json       фразы и предложения
  dialogues.json       мини-диалоги: реплика и ответ на неё
  izafet.json          изафетные пары: падар + и + ман
  REVIEW.md            всё, что помечено "verified": false — на проверку носителем
```

Файлы в `words/` и `phrases/` читаются все подряд, так что можно добавить свой
`words/99-moi-slova.json` — он попадёт в игру, если на слова сошлётся какой-нибудь уровень.

## Слово

`words/04-family.json`:

```json
{
  "theme": "family",
  "words": [
    {
      "id": "w_padar",
      "tg": "падар",
      "ru": "отец",
      "pos": "noun",
      "theme": "family",
      "example": { "tg": "Падари ман муаллим аст.", "ru": "Мой отец — учитель." },
      "audio": null,
      "verified": true,
      "note": ""
    }
  ]
}
```

| Поле | Обязательное | Что значит |
|---|---|---|
| `id` | да | Вид `w_slug`: латиница, нижний регистр, цифры и `_`. Уникален на весь курс |
| `tg` | да | Слово по-таджикски, кириллицей, в нормальной форме |
| `ru` | да | Перевод. Несколько значений — через запятую |
| `pos` | да | Часть речи: `noun` `verb` `adj` `adv` `pron` `num` `prep` `conj` `part` `interj` `phrase` |
| `theme` | да | Тема — по ней подбираются правдоподобные неверные варианты в квизе |
| `num` | нет | Число, которое обозначает слово. Только у числительных — по нему работает мини-игра «Какое это число?» |
| `example` | нет | Пример употребления: `{ "tg": "...", "ru": "..." }` |
| `audio` | нет | Задел на будущее. Сейчас всегда `null`, озвучки в игре нет |
| `verified` | да | `false` — если в слове или форме нет уверенности |
| `note` | нет | Заметка: вариант, нюанс употребления, вопрос к проверке |

`id` менять нельзя после того, как вы поиграли: к нему привязана статистика повторения.
Если слово удалить, его статистика просто перестанет учитываться.

## Фраза

`phrases/01-greetings.json`:

```json
{
  "theme": "greetings",
  "phrases": [
    {
      "id": "p_hello_how_are_you",
      "tg": "Салом, шумо чӣ хел?",
      "ru": "Здравствуйте, как вы?",
      "theme": "greetings",
      "words": ["w_salom"],
      "audio": null,
      "verified": true,
      "note": "вежливая форма на «вы»"
    }
  ]
}
```

`words` — необязательный список слов, которые встречаются во фразе; используется
мини-игрой «Собери фразу» и для учёта повторения. Все id должны существовать.

## Диалог

`dialogues.json` — материал для мини-игры «Что ответишь?».

```json
{
  "dialogues": [
    {
      "id": "d_ahvol",
      "theme": "greetings",
      "ask": { "tg": "Аҳволат чӣ хел?", "ru": "Как твои дела?" },
      "reply": { "tg": "Раҳмат, нағз.", "ru": "Спасибо, хорошо." },
      "words": ["w_rahmat"],
      "audio": null,
      "verified": false,
      "note": "проверить «аҳволат чӣ хел» против «корҳоят чӣ хел»"
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `id` | Вид `d_slug` |
| `theme` | Тема — по ней диалог сам попадает на уровни с такими словами |
| `ask` | Реплика собеседника. Её перевод игрок видит сразу |
| `reply` | Верный ответ. Его перевод откроется только после выбора |
| `wrong` | Необязательно: свои неверные варианты. Если не задать, возьмутся ответы из других диалогов — они верны сами по себе, но не к этому вопросу |

Диалоги не перечисляются в `course.json`: связь по теме. Дописали диалог с
`"theme": "family"` — он сам появится на семейных уровнях.

## Изафет

`izafet.json` — материал для мини-игры «Собери по-таджикски».

```json
{
  "izafet": [
    {
      "id": "iz_padari_man",
      "theme": "family",
      "head": "падар",
      "mod": "ман",
      "tg": "падари ман",
      "ru": "мой отец",
      "words": ["w_padar", "w_man"],
      "audio": null,
      "verified": true,
      "note": ""
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `head` | Главное слово — к нему приклеивается изафет |
| `mod` | Зависимое слово, идёт вторым |
| `tg` | Готовая форма целиком |
| `ru` | Перевод. По-русски порядок обратный — этому и учит задание |

Проверка при сборке следит, чтобы `head` + «и» + пробел + `mod` в точности давало `tg`.
Где склейка не по общему правилу (`зиндагӣ` → `зиндагии`, а не `зиндагӣи`), задание
не соберётся, и `npm run validate:content` скажет об этом ошибкой: показать игроку
неверное написание хуже, чем не показать задание.

Связь с уровнями — тоже по теме.

## Алфавит

`alphabet.json`:

```json
{
  "letters": [
    {
      "lower": "ғ",
      "upper": "Ғ",
      "name": "ғе",
      "sound": "звук между «г» и украинским «г», как французское r",
      "ru": null,
      "special": true,
      "note": "в русском алфавите такой буквы нет",
      "examples": ["w_gizo"],
      "verified": true
    }
  ]
}
```

| Поле | Что значит |
|---|---|
| `lower` / `upper` | Сама буква в двух регистрах |
| `name` | Как буква называется |
| `sound` | Описание звука по-русски |
| `ru` | Ближайшая русская буква или `null`, если соответствия нет |
| `special` | `true` для шести букв, которых нет в русском: ғ ӣ қ ӯ ҳ ҷ |
| `examples` | id слов-примеров из `words/` |

## Курс

`course.json` описывает карту: разделы сверху вниз, внутри — уровни.

```json
{
  "sections": [
    {
      "id": "s04",
      "title": "Семья",
      "levels": [
        {
          "id": "s04_l1",
          "title": "Родители",
          "words": ["w_padar", "w_modar"],
          "phrases": ["p_my_father"],
          "exercises": "auto",
          "boss": false
        }
      ]
    }
  ]
}
```

| Поле уровня | Что значит |
|---|---|
| `id` | Уникальный, вида `s04_l1`. К нему привязан прогресс и звёзды |
| `title` | Подпись уровня |
| `words` / `phrases` | Из чего собираются задания |
| `exercises` | `"auto"` — движок сам смешает 6–10 заданий разных типов. Либо явный список, например `[{ "type": "letter_wheel" }, { "type": "quiz_tg_ru" }]` |
| `kind` | `"alphabet"` для уроков раздела 0 — там можно обойтись без слов |
| `letters` | Буквы, с которыми знакомит уровень: `["ғ", "қ"]`. Только для `kind: "alphabet"`. Движок покажет не больше двух карточек на уровень |
| `boss` | `true` — уровень-сундук, каждый пятый |

Порядок разделов и уровней в файле = порядок на карте.

## Про `verified`

Точность важнее объёма. Всё, в чём нет уверенности — редкое слово, разговорный оборот,
глагольная форма — помечается `"verified": false` и попадает в
[REVIEW.md](REVIEW.md) с пояснением, что именно вызывает сомнение. В игре такие слова
работают наравне с остальными; пометка нужна, чтобы их было легко найти и перепроверить.

Исправили слово — поставьте `"verified": true` и уберите строку из `REVIEW.md`.
