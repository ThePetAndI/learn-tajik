# Тоҷикӣ — игра для изучения таджикского

Казуальная мобильная игра-тренажёр литературного таджикского языка (кириллица) для тех, кто
начинает с нуля. PWA: ставится на главный экран Android и полностью работает офлайн.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. Для проверки с телефона в одной Wi-Fi-сети — адрес
вида `http://192.168.x.x:5173` Vite печатает при старте (`--host` уже включён).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер с горячей перезагрузкой |
| `npm run build` | Проверка контента + типов, затем продакшен-сборка в `dist/` |
| `npm run preview` | Отдать собранный `dist/` локально — так проверяется офлайн-режим |
| `npm test` | Юнит-тесты (vitest) |
| `npm run typecheck` | Только проверка типов |
| `npm run validate:content` | Проверка JSON-файлов курса |
| `npm run review` | Пересобрать `content/REVIEW.md` из пометок `verified: false` |
| `npm run fonts` | Перекачать Nunito из Google Fonts в `src/assets/fonts` |
| `npm run fonts:check` | Убедиться, что в шрифте есть все 35 таджикских букв |
| `npm run audio:check` | Покрытие озвучкой и битые ссылки на файлы |
| `npm run icons` | Перегенерировать иконки приложения из SVG |

Service worker работает только в сборке, не в дев-режиме. Чтобы проверить офлайн:

```bash
npm run build && npm run preview
```

затем в DevTools → Network → Offline и перезагрузить страницу.

## Структура

```
content/          данные курса в JSON — слова, фразы, алфавит, карта уровней
scripts/          вспомогательные скрипты сборки (шрифты, иконки, проверка контента)
src/
  core/           ядро: DOM-хелперы, роутер, хранилище состояния, ГПСЧ, время, вибрация
  data/           модель сохранения, IndexedDB, экспорт/импорт
  domain/         чистая логика: жизни, монеты, звёзды, интервальное повторение
  game/           движок упражнений и сами мини-игры
  screens/        экраны приложения
  ui/             кнопки, HUD, таб-бар, модалки, иконки
  styles/         дизайн-токены и стили
  pwa/            service worker и установка на главный экран
```

Правило, которое стоит держать: `domain/` и `game/` не знают про DOM, `screens/` и `ui/` не
содержат игровых правил. Поэтому логику можно покрывать тестами без браузера.

## Данные курса

21 раздел, 105 уровней, 408 слов, 153 фразы, 26 диалогов, 22 изафетные пары и все 35 букв
алфавита. Всё лежит в `content/`
отдельными JSON-файлами, их можно править руками — пересборка подхватит изменения.
Формат описан в [content/README.md](content/README.md).

Слова, формы и обороты, в точности которых нет уверенности, помечены `"verified": false`
и собраны в [content/REVIEW.md](content/REVIEW.md) — это список на проверку носителем.
Файл пересобирается командой `npm run review`.

Целостность контента проверяется тестами: что все ссылки разрешаются, что в таджикских
написаниях нет русских ц щ ы ь, что у каждой буквы есть слово-пример с этой буквой
и что из каждого из 105 уровней собирается от 6 до 10 заданий.

## Мини-игры

Четырнадцать типов заданий. Движок собирает из них уровень сам: 6–10 заданий, разных
типов, в порядке от узнавания к письму.

Перед первой проверкой незнакомого слова встаёт карточка знакомства: слово, перевод,
часть речи, пример и особые буквы. Иначе первое, что игрок узнаёт о слове, — это вопрос
о нём, а угадывание не учит. Карточка не задание: попыток не записывает, на звёзды и
монеты не влияет, и на повторном проходе не появляется. Задания, где слово и так на
экране с переводом — «собери фразу», колесо букв, диалог, изафет, — знакомят сами собой
и карточки не требуют.

| Задание | Что делает |
|---|---|
| Новое слово | Карточка перед первой проверкой незнакомого слова |
| Что это значит? | Квиз на четыре варианта, таджикский → русский |
| Как сказать по-таджикски? | То же в обратную сторону — труднее |
| Найди пары | Пять слов и пять переводов, столбцы перемешаны отдельно |
| Собери фразу | Перевод предложения из банка слов, с лишними |
| Собери слова | Колесо букв: свайп по кругу, слова с русскими подсказками |
| Напиши по-таджикски | Ввод руками, с панелью ғ ӣ қ ӯ ҳ ҷ |
| Напиши фразу | Предложение целиком, без банка слов и без вариантов |
| Какая буква пропала? | В слове дырка, выбор из четырёх похожих букв |
| Верно или нет? | «китоб = книга?» на восьмисекундном таймере |
| Новая буква | Карточка со звуком и примерами, затем проверка среди похожих |
| Найди лишнее | Три слова одной темы и одно чужое |
| Что ответишь? | Мини-диалог: выбрать верную реплику |
| Какое это число? | Числительное набирается цифрами на своей клавиатуре |
| Разложи по корзинам | Шесть слов в две тематические корзины |
| Собери по-таджикски | Изафет: `падар` + и + `ман` |

«Напиши фразу» стоит последним и живёт по отдельным правилам: берётся только та фраза,
которую на этом же уровне уже собирали из слов, и только проверенная носителем. Это
единственное задание, где на экране нет ни слова материала, — фразу, которую видят
впервые, набрать с нуля нельзя. Над полем стоят пустые ячейки по числу слов: без них
«Ман ба хона меравам» и «Ба хона меравам» одинаково верны, и засчитывать местоимение
пришлось бы наугад.

Задание, для которого на уровне не хватает материала, не собирается вовсе — генератор
возвращает `null`, и движок берёт другой тип. Поэтому числа встречаются только там, где
есть числительные, а знакомство с буквой — только в разделе «Алфавит».

Мини-игры не знают ни про контент, ни про прогресс, ни про карту: они получают готовое
задание и контекст (`src/game/types.ts`). Добавить свою — это модуль в `game/exercises/`,
генератор в `game/generators/` и строчка в реестре.

## Игровые механики

- **Монеты** за верные ответы, бонус за серию, награда за уровень (первое прохождение — вдвое).
- **Жизни**: пять штук, ошибка тратит одну, одна восстанавливается за 30 минут.
- **Восстановление** — главный способ вернуть жизни: мини-сессия на словах, которые
  даются хуже всего по статистике. Восемь верных подряд возвращают жизнь, пройденная
  целиком сессия — весь запас. Монет за неё даётся втрое меньше обычного, иначе было бы
  выгоднее нарочно терять жизни.
- **Стрик** по дням, заморозка прикрывает один пропуск.
- **Дневной сундук** за выполненную цель и **колесо удачи** — раз в сутки.
- **Магазин** в две половины: «Питомцы» — четыре питомца с пятью ступенями прокачки и их
  снаряжение; «Лавка» — скины карты, бустеры и сундуки с бустерами.
- **Интервальное повторение** (SM-2 в упрощённом виде): у каждого слова своя ступень,
  коэффициент лёгкости и срок следующего показа. Ошибка возвращает слово в начало и
  показывает его снова через десять минут, верный ответ отодвигает срок вплоть до трёх
  месяцев.
- **Уровни-повторения** на карте: по одному в конце каждого раздела, с числом просроченных
  слов на значке. Жизни в них не тратятся — повторение это тренировка, а не испытание.
- **Раздел «Слова»**: всё, что встречалось, с прогрессом по ступеням, фильтрами и поиском;
  отсюда же запускается «Повторить ошибки».

## Прокачка

Три слоя, и все бонусы сводятся в одном месте — `domain/bonuses.ts`. Правила сложения
одни на всех: доли и счётчики суммируются, скидки идут одна поверх другой (50% и 50% —
это 75%, а не бесплатно), и у каждой оси свой потолок (`domain/perks.ts`). Бонусы
помогают, но не отменяют игру: больше двух бесплатных ошибок за уровень не бывает.

**Лаъл** — вторая валюта, по-таджикски «рубин» (копи Кӯҳи Лаъл на Памире). Монеты даются
за объём и намолачиваются переигрыванием, лаъл — только за глубину, и каждая награда
один раз: слово доведено до последней коробки повторения (+1), уровень пройден без единой
ошибки (+2), раздел закрыт (+5) и закрыт на все звёзды (+10), вехи серии от 3 до 365 дней.
Учёт — ключами в `state.achievements`, поэтому переигрывание лаъл не приносит. Для старых
сохранений на старте работает сверка (`domain/reconcile.ts`): всё уже заслуженное выдаётся
по тем же ключам и второй раз не выдаётся.

**Дарахти дониш** («древо знаний») — отдельная вкладка «Древо». Тридцать узлов: корень
Ниҳол («росток»), четыре ветки — Зар (золото), Сипар (щит), Дониш (знание), Бахт (удача) —
по семь узлов и общая вершина. В середине ветки сплетаются: части узлов нужен ещё и узел
соседней ветки. Узлы стоят монеты и лаъл, а у многих есть задание — только учебные вехи:
уровни, уровни без ошибок, выученные и освоенные слова, серия, повторения. Купить задание
нельзя. Узлы дают: монеты за ответы и уровни, жизни и их восстановление, щит (ошибка не
стоит жизни, но звезду снимает), дешёвые подсказки, длинное повторение, лаъл, удачу,
лишние вращения колеса, вторую награду в сундуке дня, скидку в лавке.

**Снаряжение питомцев** — 24 вещи в трёх слотах (голова, шея, оберег), четыре редкости,
у каждой свой потолок уровня. Вещи рисуются прямо на питомце — и в магазине, и на карте;
у каждого питомца свой наряд, работает наряд активного. Среди вещей — тоқӣ (тюбетейка),
салла, атласный шарф, анор, тумор, калам. Находятся в сундуках снаряжения, и сундуки
честные: шансы видны до покупки и ровно те, по которым идёт бросок (это проверяет тест
на десяти тысячах бросков); повторная находка становится осколками для улучшения;
после десяти вещей без эпической следующая — точно эпическая или лучше. Удачу поднимают
ветка Бахт и обереги. По симуляции полная коллекция — около 180 сундуков, 110 с удачей.

## Хранение прогресса

Прогресс лежит только на устройстве, в IndexedDB (с откатом на localStorage, если
IndexedDB недоступен). При первом запуске вызывается `navigator.storage.persist()`, чтобы
Android не вычистил данные вместе с кэшем.

Настройки → «Сохранить в файл» выгружает весь прогресс в JSON; «Загрузить из файла»
принимает его обратно, в том числе на другом устройстве. Файл проверяется и чинится при
импорте: битые и чужие поля отбрасываются, недостающие заполняются значениями по умолчанию.

## Лицензии

Шрифт Nunito распространяется под SIL Open Font License 1.1, текст лежит рядом с файлами
шрифта: [src/assets/fonts/OFL.txt](src/assets/fonts/OFL.txt).

«все права защищены»: смотреть можно, переиспользовать — нет. Если нужно иначе, положите
в корень `LICENSE` с текстом выбранной лицензии.

## Публикация

Приложению нужен адрес по `https` — только на нём браузер разрешает service worker,
а значит установку на телефон, офлайн и защищённое от вычистки хранилище. По локальной
сети (`npm run preview`, адрес вида `http://192.168.x.x:4173`) игра открывается и играется,
но без установки, без офлайна и с прогрессом, который браузер вправе стереть.

### GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует ветку `main` при каждом пуше:
прогоняет тесты, проверяет контент и покрытие шрифта, затем выкладывает `dist/`.
Base path вычисляется из имени репозитория, править ничего не нужно.

1. Создать репозиторий на GitHub. **Pages на бесплатном тарифе работает только с публичным
   репозиторием** — для приватного нужен план Pro и выше.
2. Подключить и запушить:

```bash
git remote add origin https://github.com/ЛОГИН/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Первый деплой запустится сам; адрес появится в **Actions** и будет вида
   `https://логин.github.io/имя-репозитория/`.

Если вместо пароля GitHub попросит токен — создать его в **Settings → Developer settings →
Personal access tokens (classic)** с правом `repo` и вставить вместо пароля.

### Перед первым пушем в публичный репозиторий

История коммитов публична вместе с кодом: GitHub показывает имя и почту автора каждого
коммита. Прежде чем добавлять `origin`, стоит проверить, чем подписаны коммиты:

```bash
git log --format='%an <%ae>' | sort -u
```

Если там настоящая почта, а светить её не хочется — задать личность репозитория до пуша:

```bash
git config --local user.name "ЛОГИН"
git config --local user.email "ID+ЛОГИН@users.noreply.github.com"
```

Точный noreply-адрес показан в **Settings → Emails** после включения *Keep my email
addresses private*. Уже сделанные коммиты этим не исправятся — их нужно переписать
(`git filter-branch --env-filter`) до первого пуша.

## Проверка на Android

1. Открыть адрес приложения в Chrome.
2. Меню (три точки) → «Добавить на главный экран» (или кнопка «Установить» в профиле).
3. Запустить с главного экрана, включить авиарежим — игра должна работать.

Вёрстка проверена в браузере на 375×812 и 360×640: ни одно задание не вылезает за край
и на короткий экран помещается без прокрутки. Но есть вещи, которые видно только на живом
телефоне — их стоит пройти глазами:

- **«Напиши по-таджикски»**: системная клавиатура выезжает и занимает пол-экрана.
  Панель ғ ӣ қ ӯ ҳ ҷ должна оставаться доступной, а кнопка «Проверить» — досягаемой.
  Буквы с панели не должны закрывать клавиатуру (тап по ним не забирает фокус у поля).
- **«Верно или нет?»**: свернуть игру на середине вопроса и вернуться — таймер должен
  продолжиться с того же места, а не обнулиться.
- **Вибрация**: верный и неверный ответ ощущаются по-разному; выключается в настройках.
- **Плавность**: прокрутка карты и переходы между заданиями на глаз без рывков.
- **Безопасные зоны**: вырез камеры сверху и полоса жестов снизу ничего не перекрывают.
