# Тоҷикӣ — игра для изучения таджикского

Казуальная мобильная игра-тренажёр литературного таджикского языка (кириллица) для тех, кто
начинает с нуля. PWA: ставится на главный экран Android и полностью работает офлайн.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется `http://localhost:5173`. Для проверки с телефона в одной Wi-Fi-сети — адрес
вида `http://192.168.x.x:5173` Vite печатает при старте (`--host` уже включён).

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер с горячей перезагрузкой |
| `npm run build` | Проверка контента + типов, затем продакшен-сборка в `dist/` |
| `npm run preview` | Отдать собранный `dist/` локально — так проверяется офлайн-режим |
| `npm test` | Юнит-тесты (vitest) |
| `npm run typecheck` | Только проверка типов |
| `npm run validate:content` | Проверка JSON-файлов курса |
| `npm run fonts` | Перекачать Nunito из Google Fonts в `src/assets/fonts` |
| `npm run fonts:check` | Убедиться, что в шрифте есть все 35 таджикских букв |
| `npm run icons` | Перегенерировать иконки приложения из SVG |

Service worker работает только в сборке, не в дев-режиме. Чтобы проверить офлайн:

```bash
npm run build && npm run preview
```

затем в DevTools → Network → Offline и перезагрузить страницу.

## Структура

```
content/          данные курса в JSON — слова, фразы, алфавит, карта уровней
scripts/          вспомогательные скрипты сборки (шрифты, иконки, проверка контента)
src/
  core/           ядро: DOM-хелперы, роутер, хранилище состояния, ГПСЧ, время, вибрация
  data/           модель сохранения, IndexedDB, экспорт/импорт
  domain/         чистая логика: жизни, монеты, звёзды, интервальное повторение
  game/           движок упражнений и сами мини-игры
  screens/        экраны приложения
  ui/             кнопки, HUD, таб-бар, модалки, иконки
  styles/         дизайн-токены и стили
  pwa/            service worker и установка на главный экран
```

Правило, которое стоит держать: `domain/` и `game/` не знают про DOM, `screens/` и `ui/` не
содержат игровых правил. Поэтому логику можно покрывать тестами без браузера.

## Данные курса

Всё содержимое лежит в `content/` отдельными JSON-файлами, их можно править руками —
пересборка подхватит изменения. Формат описан в [content/README.md](content/README.md).

Слова и фразы, в точности которых нет уверенности, помечены `"verified": false` и собраны
в [content/REVIEW.md](content/REVIEW.md).

## Хранение прогресса

Прогресс лежит только на устройстве, в IndexedDB (с откатом на localStorage, если
IndexedDB недоступен). При первом запуске вызывается `navigator.storage.persist()`, чтобы
Android не вычистил данные вместе с кэшем.

Настройки → «Сохранить в файл» выгружает весь прогресс в JSON; «Загрузить из файла»
принимает его обратно, в том числе на другом устройстве. Файл проверяется и чинится при
импорте: битые и чужие поля отбрасываются, недостающие заполняются значениями по умолчанию.

## Деплой на GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает и публикует `main` автоматически.
Base path вычисляется из имени репозитория, ничего править не нужно.

Важно: **GitHub Pages для приватного репозитория доступен только на платных тарифах**
(Pro/Team/Enterprise). На бесплатном аккаунте публиковать Pages можно только из публичного
репозитория. Альтернатива для приватного — Cloudflare Pages или Netlify, там приватные
репозитории работают на бесплатном тарифе (команда сборки `npm run build`, каталог `dist`,
переменная `VITE_BASE=/`).

### Создать приватный репозиторий и запушить

1. Открыть <https://github.com/new>, задать имя (например `learn-tajik`), выбрать
   **Private**, ничего не добавлять (ни README, ни .gitignore, ни лицензию), нажать
   **Create repository**.
2. В папке проекта:

```bash
git init -b main
git add .
git commit -m "Тоҷикӣ: каркас приложения"
git remote add origin https://github.com/ВАШ_ЛОГИН/learn-tajik.git
git push -u origin main
```

3. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. Первый деплой запустится сам после пуша; адрес появится в **Actions → Deploy → deploy**.

Если вместо пароля GitHub попросит токен — создать его в
**Settings → Developer settings → Personal access tokens → Tokens (classic)** с правом
`repo` и вставить вместо пароля.

## Проверка на Android

1. Открыть адрес Pages в Chrome.
2. Меню (три точки) → «Добавить на главный экран» (или кнопка «Установить» в профиле).
3. Запустить с главного экрана, включить авиарежим — игра должна работать.
